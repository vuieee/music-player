# Music Player tracks

Put your MP3 files here. The playlist is currently set up for these two tracks:

- `it's 5a.m and i couldn't sleep.mp3`
- `late night lofi.mp3`

Keep the filenames exactly as shown. The player reads these paths from `app.js`; it does not scan the folder automatically because this is a static GitHub Pages site.

The audio files are intentionally not included in this repository. Add only music you have the right to publish.
